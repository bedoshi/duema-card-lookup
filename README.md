# duema-card-lookup

デュエル・マスターズ(デュエマ)のカード名・効果テキストを、タカラトミー公式カードデータベース([dm.takaratomy.co.jp](https://dm.takaratomy.co.jp/card/))から検索・取得するClaude用スキルです。

## これは何をするか

デュエル・マスターズのカード名は自動生成字幕(YouTubeの自動字幕など)や聞き取りメモでしばしば誤変換されます(例: 「プライマル・サーガ」と「プライマル・スクリーム」の混同、「エムロマ」のような略称と正式名称の違いなど)。このスキルは、そうした不確かなカード名をそのまま信用せず、

1. Web検索で正式なカード名・収録弾・カードIDを特定
2. 公式カードデータベースのページを直接取得し、一次情報としてのカードテキストを確認
3. 出典URLとカード画像を添えて回答

という手順を踏むことで、存在しない効果を捏造してしまう(ハルシネーション)リスクを減らします。

## トリガー

以下のような場面で自動的に使われます。

- 「デュエル・マスターズ」「デュエマ」というキーワードが会話に含まれる
- 特定カードの効果・テキストについて質問される
- デッキ紹介やコンボ・ループ手順の解説を求められる
- 自動生成字幕やメモなど、カード名が不正確な可能性のある資料が渡される

## 使い方

1. このリポジトリの `SKILL.md` をダウンロード(またはZIP化)する
2. Claude.ai / Cowork の **Customize > Skills** を開く
3. 「+」→「+ Create skill」→「Upload a skill」からアップロードする
4. スキル一覧でトグルをONにする

詳しい手順は [Use skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude) を参照してください。

## 注意点

- カード画像はタカラトミー公式サイトへの直接リンク(ホットリンク)を埋め込む方式です。実行環境によっては画像プレビューの表示にクリックなど一手間が必要になる場合があります。
- 同名カードでも再録・強化版(例: 「龍神ヘヴィ」と「極限龍神ヘヴィ」)が存在するため、コスト・パワー・能力が完全一致するか必ず確認する設計になっています。
- 該当カードが特定できない場合は、断定せずにユーザーへ確認するようになっています。
